# Edição Final 1.0

Esta versão consolida a linha de desenvolvimento anterior em uma única base limpa.

## Decisões de UX

- A Fábrica Viva é o foco principal do Galpão.
- Controles não ficam sobre máquinas ou operadores.
- Logística não atravessa as células de produção.
- A Copa é uma área secundária aberta por um botão compacto.
- Somente uma fala de NPC é mostrada por vez.
- Máquinas têm famílias visuais diferentes e operadores executam movimento contextual.
- O dono da empresa usa o avatar criado pelo jogador e percorre um corredor lateral seguro.

## Decisões de produto

- Ciclos de 10 minutos para reduzir espera.
- Impulsos obtidos por minigame, recompensa diária e apoio social.
- Firebase é opcional e desacoplado do modo offline.
- Perfil online expõe apenas dados de jogo necessários para a experiência social.
